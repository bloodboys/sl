# 扫雷 · Minesweeper

一个 Win11 Fluent 风格的扫雷，**单文件、零依赖、零构建** —— 全部 HTML / CSS / JS 都在这一个 `minesweeper.html` 里，双击就能玩，不联网、不装东西、不上传任何数据。

除了经典玩法，还做了无猜模式、排位段位、每日挑战、战役闯关、成就系统和 3BV 统计。

## 快速开始

```bash
# 双击也行，或者：
start minesweeper.html
```

没有 `npm install`，没有 `build`，没有 CDN。整个项目就是仓库根目录那一个 HTML 文件。

## 玩法补充

### 无猜模式

普通扫雷在高雷密度下必然出现"只能靠运气"的局面。无猜模式在布雷后跑一遍约束求解器，只有能从头到尾推出所有格子（不产生二选一）的棋盘才会被采用，否则重新生成。

代价是生成耗时和可解率：高级 16×30/99 雷的可解率约 **23%**，平均要重试 **7 次**才拿到一张合格棋盘，单次生成 p95 约 7 ms。实测数据见下文「测试」。

### 连开（chord）

在一个**数字格**上左键，如果周围旗数已经等于该数字，会自动翻开其余未标记的格子。这是提速的核心操作，也是排行榜成绩的主要差距来源。

### 3BV

3BV（Bechtel's Board Benchmark Value）衡量一张棋盘的最少点击数，是国际通用的扫雷难度基准。本作按标准定义计算：把所有 0 邻雷的连通区域各算 1，再加上"不与任何 0 区域相邻"的数字格各算 1。结算时同时给出 3BV/s（效率）。

### 排位

段位依次为：倔强青铜 → 秩序白银 → 荣耀黄金 → 尊贵铂金 → 永恒钻石 → 至尊星耀 → 最强王者。前六段各分 Ⅲ / Ⅱ / Ⅰ 三个小段，王者只累计星数。

规则：

- **赢**：初级 / 中级 +1★，高级 +2★；连胜 ≥3 额外 +1★，破个人纪录额外 +1★，单局最多 +4★；
- **输**：−1★。星数降到 0 再输，先掉小段（Ⅲ→Ⅱ→Ⅰ），已经在 Ⅲ 就掉大段；青铜 Ⅲ 且 0 星是保底，不再掉；
- **赛季**：30 天一期，新赛季软重置 —— 掉一个大段、星级清零、连胜归零。

排位局与每日挑战、战役互斥，切换模式会自动退出当前模式。

## 快捷键

| 按键 | 作用 |
|---|---|
| `R` | 重开本局 |
| `1` / `2` / `3` | 初级 / 中级 / 高级 |
| `N` | 切换无猜模式 |
| `D` | 每日挑战 |
| `P` `A` `C` `I` | 排位 / 成就 / 战役 / 统计 |
| `H` | 提示（每局 3 次） |
| `T` / `S` | 切换主题 / 音效 |
| `方向键` | 移动键盘光标 |
| `空格` / `Enter` | 翻开光标所在格 |
| `F` | 在光标处插旗 |
| `Esc` | 关闭当前浮层 |

鼠标操作：左键翻开、右键插旗、数字格左键连开。触屏：轻点翻开，长按插旗。

## 无障碍

- 亮 / 暗两套主题，**首次打开时跟随系统**（`prefers-color-scheme`），之后记住你的手动选择；
- 数字配色另有一套色盲友好方案（基于 Okabe-Ito 调色板），暗色主题下有对应版本；
- 全界面次级文字对比度经过扫描，均在 WCAG AA（4.5:1）以上，唯一例外是"未获得的星级"——那是禁用态装饰，刻意压淡。

## 技术实现

- **单文件**：无构建流程、无第三方库、无网络请求，可直接 `file://` 打开；
- **存储**：全部进度存在 `localStorage`，键名前缀 `win11.minesweeper.*`（`profile` / `best` / `theme` / `sound` / `numstyle` / `noguess`），纯本地，不出机器；
- **音效**：`AudioContext` 实时合成，不带任何音频文件；
- **生成**：布雷分两步 —— 先避开首点九宫格，再对无猜模式跑约束求解验证，失败重试；用递增 token 让异步生成的旧回调自动作废，避免重开时把雷写进新局；
- **布局**：CSS Grid + Fluent 视觉（Mica 背景、圆角窗口、悬停高光），320px 宽的小屏也能完整显示。

## 测试

`analysis/` 下是一套回归测试。测试不依赖浏览器，用最小 DOM 桩把 `<script>` 抽出来在 Node 里直接跑，因此启动很快。

```bash
cd analysis

node test_game.js       # 核心规则：翻开、插旗、连开、胜负判定
node test_meta.js       # 排位、成就、赛季、每日挑战的元状态
node test_reload.js     # localStorage 读写与刷新恢复
node test_features.js   # 主题、音效、提示、自定义棋盘、3BV
node test_campaign.js   # 战役关卡解锁与星级结算
node test_noguess.js    # 无猜生成与独立求解器交叉验证
```

真实浏览器审计（需要本机有 Chrome 或 Edge）：

```bash
node audit.js           # 真实鼠标键盘操作 + 截图 + 控制台异常收集
```

最近一次全量结果：

| 脚本 | 结果 |
|---|---|
| `test_game.js` | ✅ 15 项 |
| `test_meta.js` | ✅ 73 项 |
| `test_reload.js` | ✅ 16 项 |
| `test_features.js` | ✅ 43 项 |
| `test_campaign.js` | ✅ 69 项 |
| `test_noguess.js` | ✅ 380 局交叉比对，0 处结论不一致 |

无猜生成实测（高级 16×30/99）：

```
判定一致 60/60 | 可解率 23.3% | 平均重试 7.1 次
生成耗时 平均 2.5ms  p95 7.0ms  最慢 11.3ms
```

`analysis/browser.js` 是一个零依赖的 Chrome DevTools Protocol 驱动 —— 用 Node 内置的 `fetch` / `WebSocket` 直连调试端口，不用 Puppeteer，负责真实输入与截图。`analysis/` 里另有若干 `probe_*.js`，是查对比度、数字配色时留下的一次性探测脚本。

## 兼容性

Chrome / Edge / Firefox / Safari 现代版本均可。用到了 CSS Grid、CSS 变量、`AudioContext`、`localStorage`，没有用到任何需要编译的新语法。
